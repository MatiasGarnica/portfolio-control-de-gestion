# Casos de control de gestión (datos ficticios)

Casos armados con datos inventados que replican la lógica de un negocio real. Cada uno se reproduce con los scripts de su carpeta `02_codigo`.

| Caso | Qué muestra | Ver online |
|---|---|---|
| [05 · Cadena con 12 locales](05_cadena-multisucursal/) | Tablero de dirección en 3 niveles (desvío de la red → local → causa), moneda nominal o constante, comparación contra pares con "mismos locales", explicación del responsable con **seguimiento del compromiso**, **demo con login por rol** (el filtro lo hace la base) y propuesta económica según el tamaño de la empresa | [Tablero](https://matiasgarnica.github.io/portfolio-control-de-gestion/casos/05_cadena-multisucursal/03_tableros/tablero_direccion.html) · [Demo con login](https://matiasgarnica.github.io/portfolio-control-de-gestion/casos/05_cadena-multisucursal/03_tableros/demo_login.html) |
| [06 · Pronóstico con método](06_pronostico-con-metodo/) | Cierre 2026 y base del presupuesto 2027 de la misma cadena. Compara métodos con un **backtest** (error y sesgo), muestra que el presupuesto se equivocó 3 veces más y siempre para arriba, separa precio de volumen con escenarios de inflación y usa **bandas de control** para distinguir ruido de señal | [Tablero](https://matiasgarnica.github.io/portfolio-control-de-gestion/casos/06_pronostico-con-metodo/03_tableros/pronostico.html) |
| [02 · Voz de primera línea](02_voz-de-primera-linea/) | Formulario de 1 minuto para repartidores y atención con categorías fijas, cruzado con ventas: separa "cae el mercado" de "cae la gestión". Incluye Apps Script con resumen y alerta semanal | [Tablero](https://matiasgarnica.github.io/portfolio-control-de-gestion/casos/02_voz-de-primera-linea/03_tableros/voz_primera_linea.html) |
